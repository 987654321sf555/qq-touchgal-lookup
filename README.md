# 游戏资料查找助手

个人部署的 QQ 聊天助手，用于按游戏名称查询 TouchGal 的公开游戏条目、基本信息及资源或补丁页面，并向发起查询的聊天返回来源链接。

本项目基于 [MaiBot](https://github.com/Mai-with-u/MaiBot)，查询扩展运行于本机。此仓库用于公开项目用途说明；本地插件源码暂未公开，不提供托管机器人或公开 API 代理。

## 查询方式

用户可以输入 `/touchgal 游戏名`，或通过自然语言要求查询。每次默认返回最多 3 个条目，结果缓存 10 分钟。返回内容为游戏条目及资源页面链接，不包含最终下载地址、提取码或密码，不自动下载游戏文件。

请求使用 [TouchGal 官方 Metadata API](https://developer.touchgal.com/docs/api)，按需发起，不进行批量抓取。Token 仅保存在本机，不提交到仓库，也不向聊天用户公开。

## 当前状态

本机接入代码、命令注册和未配置 Token 时的提示已完成。正在申请 TouchGal API 权限；真实接口检索与 QQ 发送验证需待申请获批、配置有效 Token 后完成。

本项目为个人非商业用途，与 TouchGal 或 MaiBot 官方无隶属关系。
